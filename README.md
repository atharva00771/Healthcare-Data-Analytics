## 📌 About the Project

**Healthcare Data Analytics** is an end-to-end data analytics project focused on healthcare billing, payment status, and city-wise financial analysis.

The project combines Excel/CSV, MySQL, Power BI, and DAX to transform healthcare data into meaningful analytical insights and interactive visualizations.

The primary objective is to develop practical data analytics skills by exploring healthcare billing patterns, writing SQL queries, creating DAX calculations, and building a business-focused Power BI dashboard.

### 🎯 Project Objectives

- Analyze healthcare billing records and payment patterns.
- Calculate total, average, minimum, and maximum billing amounts.
- Compare Completed and Pending payment statuses.
- Perform city-wise billing analysis.
- Practice basic, intermediate, and advanced SQL queries.
- Develop DAX measures and calculated columns.
- Build interactive Power BI visualizations.
- Improve analytical thinking and data storytelling skills.

### ✨ Dashboard Features

- 💰 Total billing amount
- 📈 Average billing amount
- 💳 Payment status analysis
- 🏙️ City-wise billing comparison
- 🔎 Interactive slicers and filters
- 📌 KPI cards and charts
- 📉 Comparison of billing patterns

### 📈 Key Analytical Metrics

| Metric | Purpose |
|---|---|
| Total Records | Counts healthcare records |
| Total Billing | Calculates the total billing amount |
| Average Billing | Measures average billing per record |
| Minimum Billing | Identifies the lowest billing amount |
| Maximum Billing | Identifies the highest billing amount |
| Completed Payments | Counts Completed payment records |
| Pending Payments | Counts Pending payment records |
| City-wise Billing | Compares billing across cities |

*Dashboard metrics depend on the fields and calculations available in the actual Power BI report.*
