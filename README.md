## 📌 Project Overview

This project focuses on Healthcare Data Analytics
using Power BI and SQL.

The goal is to analyze healthcare-related data,
create interactive dashboards, and solve
real-world business questions using SQL.

The project combines data visualization,
data analysis, and SQL techniques to generate
meaningful insights from healthcare data.

---

## 🎯 Project Objectives

- 📊 Build an interactive Power BI dashboard.
- 🏥 Analyze healthcare and patient-related data.
- 💰 Explore billing and financial patterns.
- 📈 Create meaningful KPIs and visualizations.
- 🗃️ Solve healthcare business questions using SQL.
- 🧠 Apply data analytics concepts to real-world scenarios.

## 🗃️ SQL Data Analysis

SQL queries are used to analyze healthcare data
and answer practical business questions.

### 📌 SQL Topics

- SELECT, WHERE & ORDER BY
- GROUP BY & HAVING
- Aggregate Functions
- CASE Statements
- JOINs
- Subqueries
- CTEs
- Window Functions
- ROW_NUMBER()
- LAG() & LEAD()

### 🧠 Example Business Questions

1. What is the total billing amount?
2. What is the average bill per patient?
3. Which patients have high billing amounts?
4. How many visits does each patient have?
5. What is the previous bill for each patient?
6. What is the next visit's bill?
7. What is the difference between current and previous bills?
