## 🌟 Project Overview

Healthcare Data Analytics is an end-to-end data analytics project designed to explore healthcare billing records, payment performance, and geographical financial patterns.

This project uses **Excel, MySQL, Power BI, and DAX** to convert raw healthcare data into meaningful insights through data cleaning, SQL analysis, calculations, and interactive dashboards.

## 🎯 Project Goals

- Analyze healthcare billing records.
- Identify Completed and Pending payments.
- Compare billing amounts across different cities.
- Calculate important financial KPIs.
- Perform SQL-based data analysis.
- Create interactive Power BI dashboards.
- Generate meaningful business insights.
